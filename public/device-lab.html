What this page checks

Responsive layouts in your current browser. It does not emulate Safari, change the browser’s user agent, or create separate logins. Panels of the same site can share cookies and storage.

If a preview is blank or refuses to connect

The site may block embedding or third-party cookies. Use Open ↗ to visit it directly. The tester cannot reliably detect blocked cross-origin frames, inspect their JavaScript errors, or capture them as screenshots.

Use your Playwright script for deeper tests

Download the runner and export your test setup. Run these commands locally with Python:

pip install playwright
playwright install chromium
python device_test.py --config device-lab.json --headed

The runner opens separate browser contexts, supports independent logins, captures screenshots and JavaScript errors, and keeps the browsers open until you press Enter. It runs on your computer; no browser backend is deployed on this Netlify site.
